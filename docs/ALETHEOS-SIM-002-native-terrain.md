# ALETHEOS-SIM-002 — Native Thalean Terrain v3.0

Status: implementation branch / cutover not authorized until verification
Paper: The Graviton on Graph HOG52002, DOI 10.5281/zenodo.23535267
Deployment: https://dev.rook.ca/aletheos/

## Purpose
Replace the physics-facing demo with a graph-intrinsic observatory. No QM, GR, physical graviton or spacetime claims. All coordinates are visualization layouts, never graph evidence.

## Primary carrier
AT4val[60,6] (Thalion / G60). Acceptance invariants: 60 vertices, 120 undirected edges, every vertex degree 4. Verify other published invariants (including triangle and automorphism counts) from the actual canonical adjacency before displaying as certified.

## Source discipline
Load exact certified source artifacts; record repository, revision, file path, hash, and derivation chain. Never synthesize graph adjacency from a visualization layout or from an expected invariant. Reject missing or mismatched sources visibly.

## First functional release
1. Native adjacency graph viewer with selectable vertex and exact neighbor list.
2. Shortest-path and distance-shell exploration computed from the same adjacency.
3. Triangle enumeration and counts with witness vertices.
4. Automorphism generator actions checked as adjacency-preserving permutations.
5. Provenance panel showing canonical input hash, algorithm version, test result and machine-readable receipt.
6. Deterministic layout seed and clear distinction between intrinsic and drawing coordinates.
7. Responsive mobile interface with usable touch selection.

## Later native layers
G15/G30 quotient and deck maps; oriented histories and cocycles; certified larger carriers including HOG52002 and G1800/G9000 constructions, with explicit carrier boundaries. No claim may move from conjecture to theorem by rendering.

## Gates before live cutover
- Input source exact and authenticated, with no guessed edges.
- All degree/edge/vertex checks pass; traversal and triangle tests pass.
- Automorphism tests pass for each admitted generator.
- No QM/GR language or old physics code reachable from public UI.
- Static deployment package inspected and tested on mobile and desktop.
- Existing live directory backed up and release/rollback receipts retained.
- Versioned paper-to-proof index and JSON verification receipt included.

## Execution sequence
Locate canonical adjacency and graph certificates in research sources; extract a pinned machine-readable fixture; implement viewer and inspector; run independent verifier; package a static build; review output; then replace the live site. This branch is a staging branch, not a production release.
