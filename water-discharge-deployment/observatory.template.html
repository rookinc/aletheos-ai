Model, registration & measured limits

A constructed water-model experiment. This is a conservative graph wave, with unit inertia and κ = c² = 1. It does not yet represent molecular occupancy, a physical droplet surface, or SI-calibrated water dynamics.

q̈ + Kq = 0
K = c²L₉₀₀₀ + κJL₉₀₀Jᵀ + gwwᵀ
P = Jᵀ   h = Pq   χ = q − Jh
w = Ja − b   b = (δ₀ − δF¹⁰⁽⁰⁾)/√2

The rank-one coupling gwwᵀ is an imposed interaction. Native edges and G900 tension alone leave the hidden subspace unexcited from this preparation. Transfer is reversible; no damping or autonomous discharge threshold is supplied.

Measurements. Each run begins at rest with q ∝ Ja, normalized separately to E₀ = 1. Full 18,000-coordinate evolution was evaluated by sparse matrix exponential. The energy ledger contains 201 full-precision samples at Δt = 0.2. At t = 40 the coupled run has 97.9065% hidden energy; this is an endpoint result, not a global maximum or physical conversion efficiency.

Rendering. Signed amplitudes are display-quantized to 16 bits using fixed scales shared across both runs for each layer. The ledger uses original full-precision values. Playback selects computed snapshots without interpolation. G60 shows the fixed preparation profile. G900 uses the registered G60 anchor layout with 15 local positions per anchor; that display assignment is not a quotient to a preferred G60 vertex. G9000 uses the B32K toroidal chart. Geometry does not enter the dynamics.

Return and time. Native F has 450 cycles of length 20. The earlier 18-step controller is a different map. Neither is identified with the dimensionless simulation clock.
