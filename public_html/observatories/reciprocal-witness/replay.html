Reproduce an encounter

The kit contains the browser's native fixtures, independent rational and numerical solvers, the measured Planck coefficients, the original compact source subsets and SHA-256 manifests. Unzip it, enter the directory, and run the checks. Scientific replay runs offline. Use Node 22 or later, Python 3.11 or later, NumPy, SciPy and SymPy. Rendering the optional Planck image also uses Pillow and SciPy 1.15 or later.

python3 tests/run-science.py
node tests/results.mjs > my-benchmarks.json

The duplicate-run identifier is a deterministic, short FNV-1a fingerprint for visual comparison. The exported JSON contains the actual preparation, clock, numbers and intervention. SHA-256 in the manifests identifies source bytes. Camera and display geometry do not enter either solver or receipt.

Browser and catalog checks

The browser suite operates visible controls and exports their JSON on 360 × 800 and 393 × 852 Android-sized touch viewports and a 1366 × 864 desktop. It compares full event receipts through both sphere geometries, reverses nesting, changes camera and local orientation, follows the counterfactual from launch, and checks sign, cut and common-drive controls. A Playwright Chromium installation is needed to run this additional suite.

python3 tests/browser.py http://localhost:8000/observatories/reciprocal-witness/

Run that command from the instrument source directory against a served copy of the release with the catalog overlay installed. The script also accepts a standalone HTML file URL with --portable. The deployment package checks the current catalog before editing and verifies the public routes after installation.
